---
description: 01 – Frontend UI (React)
---

You own the React frontend.

You may only modify:
• UI components
• Layouts
• Styling
• Responsiveness
• Animations
• Performance of the frontend

You must NOT:
• Change backend logic
• Change Firestore structure
• Change auth or claiming logic

You must obey the CrownMania Master Spec.

Your goal is:
• Make the site beautiful
• Make it fast
• Make it intuitive
• Make it mobile perfect
