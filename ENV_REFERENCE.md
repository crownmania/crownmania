# Environment Variable Reference

> Source of truth: generated by auditing every `process.env.*` / `import.meta.env.*` read in the codebase (Aug 10, 2026).
> Only variables the code **actually reads** are listed as active. Aspirational variables live in the [Planned](#planned--not-implemented) section.

**Destinations**
- **Backend** → Railway service env vars
- **Frontend** → GitHub Actions secrets (used at build time) — frontend is served by **Firebase Hosting** (not Vercel)
- **Smart contracts** → `smart-contracts/.env` (local only; contract `0x4785DBa85de01B0DB84269F3fd471dDd8461623C` is already deployed on Polygon mainnet via the Thirdweb dashboard)

| Variable | Needed when | Notes |

| `SHIPSTATION_API_KEY` / `SHIPSTATION_API_SECRET` | Shipping integration active | Backend only — see security warning below |
| `RECAPTCHA_SECRET_KEY` | Captcha verification enabled | Backend-side verify |

## Frontend — build-time (all `VITE_*` values are PUBLIC in the JS bundle)

| Variable | Required | Source |
|---|---|---|
| `VITE_API_URL` | yes | Railway backend URL |
| `VITE_FIREBASE_API_KEY` / `AUTH_DOMAIN` / `PROJECT_ID` / `STORAGE_BUCKET` / `MESSAGING_SENDER_ID` / `APP_ID` | yes | Firebase Console → Web App config |
| `VITE_FIREBASE_MEASUREMENT_ID` | no | Analytics only |
| `VITE_FIREBASE_VAPID_KEY` | no | Web push only |
| `VITE_WEB3AUTH_CLIENT_ID` / `VITE_WEB3AUTH_NETWORK` | yes | Web3Auth dashboard |
| `VITE_WEB3_RPC_TARGET` / `VITE_WEB3_CHAIN_ID` | yes | Public RPC + chain (137) |
| `VITE_STRIPE_PUBLISHABLE_KEY` (alias `VITE_STRIPE_PUBLIC_KEY`) | yes | Stripe `pk_...` only |
| `VITE_MORALIS_API_KEY` | no | Only if client-side Moralis enabled |
| `VITE_SITE_PASSWORD` | no | ⚠️ visible to anyone reading the bundle |

> ### ⚠️ SECURITY — do not set these
> `VITE_SHIPSTATION_API_KEY` and `VITE_SHIPSTATION_API_SECRET` are read by frontend code. Any value set for them ships in the public JS bundle. **Leave them unset** and route ShipStation calls through the backend. (Tracked as an open security item.)

| Variable | Notes |

## Planned — NOT implemented (do not set; no code reads these)

These came from the target-state architecture review and require code changes before they do anything:

| Variable | Would enable |
|---|---|
| `CORS_ALLOWED_ORIGINS` | Env-driven CORS (currently hardcoded in `src/server.js`) |
| `REDIS_REQUIRED_IN_PRODUCTION` | Fail-closed startup when Redis is down |
| `REDIS_STRICT_NONCE` / `NONCE_TTL_SECONDS` | Strict replay protection across instances |
| `METRICS_ENABLED` | `/metrics` endpoint (none exists) |
| `DATABASE_URL` / `POSTGRES_URL` / `DUAL_WRITE_ENABLED` / `DUAL_WRITE_TARGETS` / `CLAIM_READ_SOURCE` | Postgres migration with dual-write (no Postgres/Prisma in repo) |
| `THIRDWEB_CHAIN_ID` / `THIRDWEB_SDK_NETWORK` | Redundant — network already derives from `POLYGON_CHAIN_ID` |
| `VITE_RECAPTCHA_SITE_KEY` | Frontend captcha rendering (not wired) |
| `NEXT_PUBLIC_AUTH_PROVIDER` | Invalid — this is a Vite app; `NEXT_PUBLIC_*` vars are never exposed |
